# Skills

## 功能与定位

管理特定任务应如何执行的说明、SOP 与参考资料，帮助 Runtime 为当前任务选择合适方法。

当前为目录骨架，没有子目录或业务实现。

## 后续组件规划

| 组件 | 一句话概述 |
|---|---|
| SkillManager | 列举、选择并加载任务相关 Skill。 |
| SkillCatalog | 管理 Skill 标识、描述和触发提示等元数据。 |
| 参考资料加载 | 按需加载 Skill 引用内容，避免一次注入全部材料。 |

## 设计边界

Skill 是任务方法，不是工具实现或执行引擎；选择 Skill 不等于直接推进执行。
第一版可使用确定性关键词选择，具体内容由 Context 注入；允许工具列表还需由实际工具执行边界落实，不能仅依赖模型遵守。
