# Users

## 功能与定位

定义用户公共标识、轻量资料快照和资料管理协议，使用户级记忆等数据能够关联到同一主体。

当前只有契约，没有用户管理器、用户存储或认证实现。

## 直属子模块

| 子模块 | 一句话概述 |
|---|---|
| [Models](./Models/Models.md) | 定义 UserId 和包含显示名称、创建与更新时间的 UserInfo。 |
| [Operations](./Operations/Operations.md) | 定义用户创建、查询、列举和显示名称更新协议。 |

## 设计边界

- UserId 仅标识用户，不包含凭据、角色或访问授权。
- 用户身份应由可信入口建立，不能让模型任意指定其他用户的 ID。
- 默认 UserId 可能无效，模块入口仍需校验。
- 创建资料不等于登录或认证，DisplayName 不是唯一身份键，允许重名。
- 当前不设计多租户、删除、禁用、角色、密码或外部身份绑定。
- [Sessions](../Sessions/Sessions.md) 已通过 UserId 建立单用户归属；一个用户可有多个会话，创建会话时须校验用户存在性和权限。
- User 级 MemoryOwner 继续使用 UserId；构造校验只验证归属结构，不证明用户存在或调用方有权限。
- UserInfo 是资料快照，不包含全部会话、任务或记忆列表；具体保存方式由后续存储实现负责。

UserId 已移到 Models 命名空间，Memory 引用同步迁移，JSON 的 Value 结构保持不变。
