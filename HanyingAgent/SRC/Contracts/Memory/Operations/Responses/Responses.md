# Responses

## 功能与定位

定义某次操作特有的结果，不重复包装本来就可以直接返回的记忆模型。

当前无子目录，只有 [MemorySearchResult](./MemorySearchResult.cs)：包含一条 MemoryItem 与当前查询产生的 Score。

## 设计边界

- Score 来自检索后端或重排序过程，越高表示在本次检索中排名越靠前。
- Score 不是记忆的固定属性，不是 Confidence，也不是正确率。
- 不保证 Score 位于 0 到 1，也不保证不同检索后端的分数可直接比较。
- 工作记忆直接返回 MemoryItem 列表，不伪造搜索分数。
- 长期检索实现返回前应核对权威数据，避免把已删除、失效或越权的索引命中交给调用方；当前仅定义结果结构。
