# State

## 功能与定位

管理任务运行到哪里以及下一步应从哪里继续，是执行进度的权威业务管理者。

当前为目录骨架，没有子目录或业务实现。

## 后续组件规划

| 组件 | 一句话概述 |
|---|---|
| StateManager | 创建任务状态并执行显式进度或状态变更。 |
| 转换规则 | 拒绝终态重启等非法转换并记录变更原因。 |
| 进度与版本控制 | 管理迭代、Chain 步骤、工具执行进度与并发版本检查。 |
| 状态存储端口 | 隔离状态规则与具体保存方式。 |

## 设计边界

State 回答执行位置，Memory 回答已知信息，两者不能互相代替。
状态验证与更新应原子完成，不向调用方暴露任意更新委托。
可恢复进度还需关联待执行动作和已完成结果，不能只恢复一个展示状态；具体存储放在 Infrastructure。
